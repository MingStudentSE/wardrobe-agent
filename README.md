# wardrobe-agent

本地优先的电子衣橱与 AI 穿搭助理。

## 项目状态

准备开发：当前已整理需求、参考项目审计与架构草案，尚未实现应用。

设计方向为桌面优先的 React + Tauri、共享 Rust 核心与每设备 SQLite，提供 GUI、CLI 与 MCP 入口。详细范围与设计决策以 `docs/` 中的文档为准。

## UI 设计

使用项目级 `hallmark` 设计技能。Beta 只交付桌面端，同时为后续 Android 保留共享视觉语言、窄屏布局与触摸操作基础。参见 [UI 设计与跨端适配](docs/04-UI设计与跨端适配.md)。
