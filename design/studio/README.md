# 衣间 · 私人衣橱工作室

以 ui-ux-pro-max 为设计依据的独立交互预览。暖白、炭色、墨绿；中文无衬线排版；桌面侧栏、窄屏底部导航；单品图片优先。

运行：`python3 -m http.server 8791 --bind 127.0.0.1 --directory design/studio`

访问 http://127.0.0.1:8791/ 。无需安装依赖，不加载外部字体或图片。

包含衣橱、穿搭、记录、设置四个入口，以及搜索、分类、季节/收藏筛选、排序、单品详情/编辑、图片录入、搭配创建与穿着记录。抽屉支持焦点约束、Escape、未保存修改提醒。关键动作不依赖 hover。

示例品牌、价格、衣物插画和穿着记录仅用于设计预览。衣物编辑保存至浏览器 localStorage；搭配、日记及设置仅在当前页面会话内保存。AI 推荐为预设展示，试穿/同步/模型设置未接入真实服务。此预览不是桌面生产应用的集成交付。
