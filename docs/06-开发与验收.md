### 使用

```sh
cargo test --workspace
cargo build --workspace
cargo run -p wardrobe-cli -- space.default
cargo run -p wardrobe-cli -- clothing.create '{"member_id":"default","name":"白色衬衫","category":"top","seasons":["spring"],"price_minor":12900,"currency":"CNY"}'
cargo run -p wardrobe-cli -- clothing.list '{"member_id":"default","limit":24}'
cargo run -p wardrobe-cli -- mcp
cd apps/desktop
npm ci
npm run tauri dev
```

三入口读取同一默认数据目录；可通过 `WARDROBE_DATA_DIR` 指定测试空间。CLI 支持 `--db <路径>` 与 stdout JSON `{result}`/`{error:{code,message}}`；失败 exit 1（存储）或 2（调用）。MCP 使用标准 stdio 一行一条 JSON-RPC；初始化、tools/list、tools/call、resources/list/read 和 ping，日志不写入 stdout。MCP 资源 `wardrobe://capabilities` 只包含真实已实现能力。

开发浏览器预览 `npm run dev` 只用于验证界面，通过 loopback Vite 中间件调用本地已构建 CLI；没有假库存或假保存。正式应用使用 Tauri command。此预览不是对外 Web/REST 产品。先 `cargo build --workspace`，再预览。
