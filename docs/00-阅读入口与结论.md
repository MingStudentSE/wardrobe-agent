## 研究结论

Wardrowbe 提供完整业务闭环（包含洗护、Lookbook、配对、多图和外部写回），适合作功能与领域基线，但依赖服务器数据库和队列。

AIWardrobe 提供简洁录入、抠图、场景规则与解释性推荐；数据模型不完整，原图不保留，key 明文落盘，不能直接作为最终本地核心。

ClosetAI 提供原图/衍生图、本地 Vision 抠图、生成式搭配图、试穿对比和 Keychain。当前主入口为手动选衣；“久未穿”按搭配创建而非真实 WearLog 统计。README 宣称 MIT，当前仓库缺 LICENSE；复制代码前需要补全许可证据。

最终设计建议：桌面优先的 Tauri/React + Rust 核心 + 每设备 SQLite。GUI/CLI/MCP 使用同一 schema 和应用命令；CLI/MCP 不依赖 GUI。一个工具型 Stylist Agent 管理可验证工作流，规则/代码验证库存与推荐结果，长任务交给持久队列。S3-compatible/WebDAV/Local Folder 只传加密变更和媒体，独立 Sync Engine 负责因果版本、冲突、删除与恢复。手机共享协议/核心，平台能力另适配。

- 历史衣橱偏好来自本地记忆，并标为历史来源，不视为本次用户逐项批准。
- 架构是可供评审/开发的推荐设计；不是已经构建的跨平台安装包或完成验证的同步协议。
