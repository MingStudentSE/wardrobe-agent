# 私人衣橱工作室：完整前端集成

2026-10-07。用户确认设计预览并授权将 UI 应用到完整前端。设计依据 ui-ux-pro-max，旧 Hallmark 要求已撤销。

## 集成范围

实际应用位于 apps/desktop；原 design/studio 保留为设计参考，不把假数据或 localStorage 操作移入生产。

- 衣橱：成员选择、录入/批量录入、搜索/组合筛选/分页、详情编辑、收藏、归档和回收站；单品中接入识别、图片管理与商品展示图。
- 穿搭：Lookbook、创建/编辑/克隆/收藏/恢复、本地拼贴、搭配生成、反馈、虚拟试穿。
- 记录：实际穿着记录、更正/撤销、洞察、洗护。
- 设置：模型与凭据、天气与学习偏好、CLI/MCP 客户端授权、加密设备、备份恢复/数据目录迁移、真实后台任务概览。
- 统一暖白/炭色/墨绿 tokens、无衬线中文、图片网格、窄屏底部导航、居中单品弹窗。

GUI 继续调用 api.ts；Tauri 调用共享 Application API，开发网页经仅 loopback 的 Vite 中间件调用同一独立 CLI。CLI 和 MCP 无删除或业务行为修改。当前核心注册 157 个操作。

## 新增衣物窗口重设计

新增独立 CreateItem 表单：先选本地照片，填写名称、类别、品牌、季节；购买信息与详细属性分别按需展开。取消和添加操作固定在窗口底部。图片先通过 Core 导入，创建单品后采用图片；采用失败保留已创建 ID，重试继续关联，避免重复创建。浏览器开发桥临时接收图片并交给真实 CLI 导入，随后清理临时文件；生产版本使用 Tauri 本地文件选择。
