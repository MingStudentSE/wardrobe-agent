## 浏览器与安全专项（本轮实测）

- 引导：一次性令牌文件（0600）→ 恰好一次 → 令牌文件消费后不可复用（e2e）。
- 会话：HttpOnly+SameSite=Strict Cookie 属性断言；服务内存会话；登出/撤销即时生效；连接令牌不出现在 Cookie/页面状态/日志。
- CSRF 三层负向：伪造 Host 403、缺失/跨源 Origin 403、缺失/错误 CSRF 头 403（行为测试+真实浏览器 e2e）。
- 上传边界：20MiB/64MiB/100 文件/类型白名单；拒绝不落残留；任意服务器路径不可由浏览器指定。
- 窄屏与键盘：375px 无页面级横向溢出；skip-link 键盘可达并聚焦主内容。
