交付 wardrobe-agent 的完整桌面 Beta：F01–F30 全部完成，本轮发布 macOS DMG；Windows EXE 和 Linux DEB 延后，保持跨平台架构。提供本地优先的衣橱、手工搭配、穿着/洗护、分析、内置 Stylist Agent、外部 CLI/MCP、图片生成与试穿、定时通知、加密同步和备份恢复。设计统一 UI，桌面交付期间验证窄屏和触摸基础，Android 后续。

产品开源且无应用收费、订阅、充值、会员或付费生成入口。用户自行配置 API 或本地模型，调用消耗其模型供应商额度。全部业务操作能力提供，不以付费分层限制。内部开发顺序不改变完整 Beta 发布范围。

## Implementation Decisions

- 架构采用模块化单体、React/TypeScript/Tauri 桌面入口、共享 Rust Application API 和每设备 SQLite。GUI、CLI、MCP 使用同一领域命令、查询和版本化 schema；CLI/MCP 不依赖 GUI 启动。采用领域、数据、媒体、任务、推荐、Agent、providers、同步与存储适配边界，初期可用内部模块实现以避免过早拆包。
- 全部 F01–F30 是 Beta 必交：独立成员、录入/属性/维护、识别/处理/商品图、手工搭配、推荐/控制/反馈、穿着、洞察、调度、搭配图、试穿、Agent、学习、CLI/MCP、同步、备份、设置、macOS 发行与跨平台架构、洗护、多图、Lookbook/Studio、配对、外部 Agent 与所有基线细节。每项有可追溯验收，不接受占位接口完成判定。
- 核心流程参考固定提交的 Wardrowbe、AIWardrobe、ClosetAI：前者提供领域闭环和持久队列思路，后两者提供低摩擦识别纠错与原图/衍生图分离。参考不等于代码复用或实测通过；不继承明文密钥、硬删除、丢原图、错误穿着口径或输入静默截断。
- UUIDv7 作为实体身份；schema 版本、创建/修改时间、成员范围统一。时间保存 UTC，穿着和洗护另存当地日期与 IANA 时区；价格为最小货币单位整数加 ISO 币种。未知值为 null 或未设置，不捏造尺寸、价格和日期。
- 单品必填身份、成员、名称、类别和生命周期状态；名称 1–120 字符，草稿默认“未命名单品”，允许无图占位。大类为上装、下装、外套、连衣裙、连体、鞋、包、配饰、内衣、运动服和其他；小类版本化。四季固定多选，未知可空，“四季”展开为四项。颜色/图案/材质/风格/场合/标签可多选；品牌、尺寸标签、版型、描述、备注、购入信息可选。备注最多 10000 字符。
- 生命周期 active/archived/deleted 与收藏、待洗分离。归档/删除不改写历史。AI 识别值保存来源、模型和不确定项，人工确认后才成为事实，人工修改优先；模型自报置信度不作为校准准确率。
- 每单品最多 20 图，每批最多 100 文件；导入目标 JPEG/PNG/WebP/HEIC，单文件上限 50 MiB、解码上限 60 MP。默认每文件一个草稿，可归并多图；多件衣物照片不自动分割实体。逐项失败可恢复，原文件不受影响。
- 先保留本地原图，再规范方向、处理展示衍生图和可选 AI，最后审核提交。统一压缩即使不用 AI 也执行；初始最长边 1600px、不放大，WebP/JPEG、质量约 82、常见 150–400KB、500KB 软阈值，细节损坏时允许超软阈值，参数按样图验证。生成商品图先预览再采用，失败/取消保留旧图，重新生成显式启动。
- 图片按角色、采用状态与同步范围管理。仅最终采用的压缩商品展示图跨设备同步；原图、缩略图缓存、中间图、生成搭配图、试穿图和真人参考图仅本地。共享数据不携带原图路径、源文件名或 EXIF/GPS。新设备从商品图本地重建缩略图；重新生成需要原设备或重新导入。用户指令下向模型发送图片与设备同步是不同通道。
- 手工搭配至少一个同成员真实单品，不重复，角色/层次独立表达，允许不完整组合；不依赖云模型，保存不记穿着。模板编辑不改变历史快照，本地拼贴离线可用，AI 搭配图失败不丢搭配。
- 实际穿着使用稳定 WearEvent，补记、更正与撤销可追溯；同日换装允许多事件。穿着次数按有效事件计，穿着天数按当地日期去重；重复点击/重试使用幂等键。禁止把未来计划、喜欢、接受推荐或保存搭配当实际穿着。久未穿默认 90 天且可配置，从未穿过单列。
- 洗护阈值为正整数或未设，默认未设；用户手动标记或达到阈值为待洗。清洗/干洗重置计数，维护默认不重置；更正和补记按时间顺序重算。评分为总体/舒适/风格各 1–5 可选整数，画像从事实/反馈重算并可重置。
- 推荐默认 3 套，允许 1–5；可行数量不足给原因。规则候选/组合校验先处理成员、存在性、固定/排除和不可用状态等硬约束，LLM 组织与解释，失败有限重试后规则回退。近期 7 个自然日避免重复为软约束，放宽须解释。目标优先/库存优先、配对、当天排除和换套均实现。天气手动可替代，缓存超过 3 小时标过期。
- 内置 Stylist 支持今日、婚礼/面试、旅行与打包、分析、购买适配；购买候选不入库存。Agent 使用领域工具，不直接 SQL 或任意文件/网络执行。统计数字来自确定性查询，未知事实明确未知。
- Application API 为三入口共同契约，覆盖能力发现、成员、单品/资产、搭配/Lookbook/配对、推荐、穿着/洗护/反馈、偏好/学习/分析、上下文、图片、任务、调度、同步/冲突和备份/恢复。工具采用稳定名、input/output schema、分页、类型化错误、成员与客户端 scope；长任务立即返回任务 ID。外部 Agent 可授予完整业务范围并关闭内置 AI。
- 完整授权后不逐次重复权限确认；显式指令、生成动作或启用计划授权相应模型调用。仍执行成员、schema、资产白名单和幂等检查。删除使用详情/编辑入口和回收站；永久清理、覆盖恢复、密钥更换使用明确专门动作。不存在应用收费选择。显示实际 provider、输入、可获得用量和调用错误，不捏造余额/价格。
- 任务 queued/running/waiting_input/succeeded/failed/cancelled 持久化，支持查询/取消/重试。网络/限流最多自动重试 2 次并遵守 retry-after；认证/参数/能力错误不重试。生成结果未知时先查状态，无法查询进入待核对，不能盲重发消耗额度；取消不保证撤回已消耗额度。
- 图片/试穿适配器声明输入数量、分辨率、异步等能力并校验，不静默截断。文本/视觉支持可配置 OpenAI-compatible 端点；真实验证 provider 能力覆盖识别、推荐、商品图、搭配图、试穿和 Agent，不把文本兼容性当成全部能力保证。
- SQLite WAL、外键与短事务；领域写入和 outbox/audit 同事务，inbox 去重。迁移跨进程锁，任务 lease 原子 claim，崩溃可恢复，GUI/CLI/MCP 并存。凭据使用各平台安全存储，不进入源码、日志、普通配置或同步包。
- 同步使用公共 SyncStorage 契约与 S3-compatible/WebDAV/本地文件夹适配器，业务与同步引擎不依赖厂商类型。不可变加密日志/blobs、完整性校验、发布标记、分页和能力声明；不假定 ETag 是内容 hash 或所有后端支持原子覆盖。三后端共同契约测试，更换目标可校验并回退，首版一个主目标及镜像备份。
- 因果版本检测并发，不用时间戳裁决事实。不同字段自动合并，同字段不同值保留双方；集合采用操作式增删语义；搭配结构冲突人工处理。事件去重，tombstone 防迟到更新复活，恢复为显式动作，缺图占位重试。日志/blob 清理需要确认水位和恢复保留条件。
- 同步 E2EE、设备配对、恢复密钥、改密码、撤销设备和密钥轮换完整实现；算法/库参数工程验证和审查后确定，不照抄示例。备份一致性、格式版本、恢复预览与实际恢复提供，标明是否包含原图；同步备份不偷偷带原图。
- 定时计划保存成员、星期、当地时间/时区、执行设备与启用状态；休眠恢复默认补最近 2 小时，每计划最多一次，过旧标错过。用户可调整窗口；后台与开机启动显式设置，关机不保证执行。系统通知和个人计划保留。
- 统一 tokens、中文排版、导航语义和状态，既有系统建立后不逐页轮换主题。桌面侧栏/多列/双栏与后续 Android 底部或抽屉导航/单列分别适配；关键操作不依赖 hover/拖拽。支持键盘焦点、触摸等价、字体缩放、安全区和减少动效。

## Testing Decisions

测试边界已于 2026-10-07 经用户确认。

- 主要测试边界是统一 Application API 的 commands/queries。用真实 SQLite、临时资产目录运行用户级命令链，验证外部可见结果、事件统计、资产与持久恢复；不测试内部函数调用次数、私有实现结构或按代码镜像生成断言。
- 确定性场景仅替换不可控的模型/天气、时钟和外部故障源。通过同一高层 API 覆盖领域、数据、媒体、任务、推荐、学习、调度、同步与备份；不为每层人为新增测试入口。真实 provider 集成和真实安装验收不能被 mock 结果替代。
- 三入口补充薄契约测试：GUI、CLI、MCP 操作相同 fixture 得同一结果，GUI 未启动时后两者仍工作；覆盖分页、错误、scope、任务 ID 和成员隔离。GUI 单独做关键流程端到端与可访问性验证。
- 同步适配器存在独立外部契约，三后端复用同一套往返、分页、条件竞争、截断上传、认证、超时、限流、删除与收敛测试；两空间实例经 API 验证重复/乱序/离线、同字段/不同字段、删改冲突、缺 blob、时钟偏差、密钥轮换和迁移失败。
- 测试先例：当前仓库只有研究和规格，没有应用代码、现成测试 seam 或测试套件。沿用已有 F01–F30 验收矩阵、图片规则和同步故障场景作为行为 oracle；参考项目静态源码不是本项目的测试通过证据。
- F01–F30 每项均需要自动化检查或可复现演示/人工验收记录；覆盖两成员隔离、混合批量失败/恢复、字段往返、软删除恢复、AI 纠错、样图质量、商品图采用、离线拼贴、硬约束、换套、反馈/穿着分离、统计、休眠调度、真实试穿/flat-lay、五类 Agent 场景、画像重置、外部写回、设置安全以及 macOS 发行与跨平台架构审查。
- 使用已知事件 fixture 明确预期：同日同单品两次有效穿着=两次/一天；重试同操作不增加次数；保存或接受搭配次数不变；改模板不改历史；清洗后计数重置且补记更正可重算；不可用/错误成员/不存在 ID 无法成为推荐结果。
- 图片至少 20 张含白衣、细纹、印花、方向与大图样本；压缩前后并排检查，原图字节不变；同步包/快照/重试/对话附件不含禁止资产、凭据或 EXIF/GPS。真实图片模型调用记录 provider/模型/限制和结果，失败/未知/取消行为可复现。
- UI 在 1024/1280/1440px 和窄窗口检查桌面；在 320/375/414/768px 检查适配基础。核心页面无页面级横向溢出或遮挡动作，键盘与触摸均能操作；空、长名称、多图、加载、错误、离线、保存反馈和减少动画均覆盖。
- 本轮 macOS 记录测试机器，在 4 核/8GB RAM/SSD、10000 单品和 100000 穿着事件基线上，每项至少 30 次采样；冷启动至可交互 ≤5秒，本地搜索/筛选首屏 p95 ≤500ms，普通实体保存 p95 ≤300ms，不含图片和网络耗时。实测不达标不能声称满足目标。
- 发布门槛：F01–F30 全通过，macOS 干净安装/升级/卸载保留数据/备份恢复与 GUI/CLI/MCP 独立运行通过，并完成跨平台架构审查，有可下载产物、签名公证/依赖记录、许可清单、迁移说明、已知限制和测试报告，才可标记完整 Beta 完成。

## Out of Scope

- Android 安装包及完整移动发行、iOS 承诺；Beta 仍须具备窄屏/触摸适配基础与共享协议。
- 家庭邀请、多人协作、共享角色/权限或家人评价；独立成员档案仍属范围。
- 应用收费、会员、订阅、充值、付费生成入口或项目托管模型额度。
- 默认 REST 公网托管服务、自建云、原 Obsidian 数据导入以及 S3/WebDAV/本地文件夹以外的专有云盘适配。
- 多主同步目标同时双向协调、一张照片自动分割多衣物、自动购买或根据试穿图保证真实合身/尺寸。
- 原图/真人图/试穿结果/AI 搭配图默认跨设备同步，或以附件绕过同步白名单。
- 首版要求多个互相聊天的专门 Agent、微服务、服务器数据库/Redis/Docker 部署，或默认本地 AI 已安装。
