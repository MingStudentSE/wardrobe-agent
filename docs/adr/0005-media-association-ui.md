# ADR 0005：单品图片采用与关联管理

状态：已采用（2026-10-07），父规格 #1、图片切片 #5。

已保存单品的详情提供系统文件选择、多文件逐项导入、压缩图预览与显式采用。新采用图片追加到 `asset_ids`，不清空此前图片；`display_asset_id` 独立选择主图。排序必须完整包含已有 ID 且不重复，不通过排序偷偷添加或删除。GUI 以向前/向后按钮提供触摸和键盘等价动作，不依赖拖拽。

`assets.detach` 只移除当前成员单品的关联，保留本地文件、其他单品引用及旧 audit 快照。移除主图后第一张剩余图片接替，无剩余时主图为 null。若图片没有任何当前成员单品引用，恢复 preview/local_only 状态，避免无关联资产继续进入同步白名单；已删除单品仍保留引用。修改、删除和恢复单品继续保留现有资产 ID。所有关联写入使用 `begin_write()` 并与 audit/outbox 同事务提交，更新单品 UTC 修改时间。

文件选择开始前进入共享 mutation busy 状态，直到导入/采用/排序/移除及列表刷新结束；成员选择、详情跳转与保存均受保护。失败项独立显示错误及重试按钮，已完成项不丢失。图片读取失败提供重新读取；前端不把原图当作展示兜底。

浏览器验证仅替换系统文件选择器这个外部边界；通过真实 CLI/Application API、SQLite、本地 PNG/HEIC 与解码限额样本运行导入、预览、采用、编辑、排序、移除和重新打开。原生系统文件选择与三平台安装仍由原生发行验收覆盖。GUI 七宽度截图记录在本次测试输出；样图质量的至少 20 张检查仍归图片切片整体验收，不能用少量合成 fixture 替代。
