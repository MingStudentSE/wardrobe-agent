# ADR 0020 · 离线搭配推荐意图与批量可用性投影

状态：采用。对应 #15，F09/F10/F30。

推荐是本地意图，不是实际穿着。推荐数量默认三套、允许一至五套；成员、实物存在、生命周期、洗护可用性、固定与排除属于硬条件。最近七个本地自然日有效实际穿着的整套组合属于软避重复，仅在硬条件下库存不足时显式放宽。收藏、有效穿着频次、库存优先与已记录场合标签参与排序，不推断未知衣物事实。

选择持久化不可变 `recommendation_intents` 和显式保存收据 `recommendation_saves`（DB15）。保留当时控制、真实衣物ID、角色层级、缺货与放宽解释。替换及换套创建子意图，原意图不改写。单品替换保留其余衣物；换整套恢复用户固定条件并排除上次实物集合。保存重新检查当前可用性，在一个 IMMEDIATE 事务内调用共享搭配写入流程并写收据，重试不重复创建模板；不调用 wear.record。

可用性沿用有效穿着与洗护历史，按成员一次读取各来源，再按物理单品ID分组投影。查询保持 DEFERRED 快照；推荐写入内复用 IMMEDIATE 快照。不得持久化可变穿着计数作为真相。组合通过角色槽位的优先队列邻居展开，不遍历完整笛卡尔积；固定条件预先应用，不用候选截断掩盖稀有固定衣物。

角色规则支持上装+下装+鞋，或连衣裙/连体衣物+鞋；固定外套、包、配饰、内衣、运动服与其他物品保留明确角色。未知运动服或其他类别不视为全身覆盖。缺少基础角色展示真实部分组合并说明缺货，不能以同一组ID的排列充当不同方案。

天气可关闭或手动温度/位置。手工来源、获取时间与超过三小时的过期状态明确返回；15°C及以下要求外层但不承诺保暖性能。离线规则不需要凭据或网络。自动天气、日程及智能代理属于各自后续 ticket；本票不声称真实云模型、自动天气或最终性能门槛已通过。
