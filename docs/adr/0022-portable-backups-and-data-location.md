# ADR0022：便携事实备份与本机数据目录

状态：实施中，#32；独立验收前不称为采用完成。

普通备份是用户明确保存的本地明文资料包，范围包括成员、当前衣物、不可变搭配版本、穿着及护理修订、保存收据、洞察设置、历史展示引用和展示图片。原图是独立显式选项。界面说明范围与明文性质；不把普通备份称为同步密文包。

在一个 SQLite 读事务中逐行构造新的白名单事实数据库，媒体逐文件流式复制、哈希与长度校验，最后发布目录。原数据库页、客户端授权、供应商配置、OS密钥、AEAD钱包、配对记录和设备序列从未写入便携备份暂存。未采用的本机任务与模型缓存不充当跨安装业务事实；恢复后的配置与模型获取需要本机明确处理。新增已接受领域实体由对应模块接入备份白名单，并在最终联合验收覆盖，不以全库导出代替资产授权。

恢复先只读验证格式、实际数据库版本、结构、引用与所有文件hash。明确覆盖时先生成当前事实与原图的真实预备备份；展示媒体先暂存，业务记录在同一IMMEDIATE事务覆盖，失败不改变当前事实。保留旧媒体与预备备份供回退。安装凭据与设备信任不能随备份继承；ADR0012恢复材料及恢复secret独立于普通备份，恢复后的新设备须显式恢复/配对，不复制旧设备序列。

数据目录迁移是同一安装的本机搬迁，不是便携导出：复制并验证实际数据库及本机文件后才发布位置切换，旧目录保留。既有进程的共享Application入口与新CLI/MCP打开均读取新目录；失败保持原位置。此动作不能替用户读取或覆盖真实库作测试。

DB17创建真正需要持久化的本机backup_preferences（默认备份目录、原图选择、设置revision）；便携备份排除该本机路径设置，目录迁移保留。实现不能按全局数据库版本跳过其他模块实际表修复。#35负责三平台安装/升级/恢复最终发行验收及完整规模基线。

恢复先把清单内文件流式拷贝到自有目录，再对该副本完整预览；实际导入不重新读取可变的外部包，也不采用未列出的文件。展示媒体按内容识别并核对尺寸，传输对象名无需扩展名。新白名单数据库不需要复制私有页后再清理，也不为大库产生一次全量 VACUUM 临时副本。

DB17同时持久化本机 local_installation_state.generation。恢复事务递增代际，旧连接获得写锁后再次核验；授权后的执行始终保持原连接，不能经过可信本机自动重开丢失 token 上下文。代际不导出，恢复旧预备备份也不倒退。本机目录迁移完整保留它。

位置发布采用 pending/active 标记和安装专用进程锁：pending 时公共操作拒绝；提交后才发布 active。进程中断且锁已释放的 pending 由公共打开入口清除，仍读取旧源。获旧数据库写锁后重查位置，避免先前已阻塞的写入提交到过期副本。三平台掉电持久性不由 macOS 的进程中断测试替代。

长维护操作先持久排队并立即返回 job_id；worker、查询、取消与显式恢复通过公共维护入口实现。维护队列属于全空间，不挂默认成员外键，也不出现在成员 jobs 中。成员受限授权拒绝所有维护入口；细粒度授权必须覆盖任务原业务操作。真实覆盖恢复在事实事务内记录完成收据，不能由已提交后的取消撤销事实。

每个维护 worker 持有不 unlink 的安装文件锁，lease 到期不能越过仍活跃的 OS 锁。Unix 校验打开文件和路径的 dev/ino/nlink；目录搬迁保留原锁 URI，旧源仍保留。取消检查与续租处于同一 IMMEDIATE 事务。创建资料包发布后中断可验证带本任务 ID 的清单并恢复真实结果；目录 active 标记发布后可核验并补齐任务收据。pending 读取后获得锁必须重新读取标记，不能误删已发布 active。

恢复事务捕获旧 provider jobs 已提交/未知调用的最小安全收据到本机 local_submission_guards；以实际 space_id、member_id、kind、operation_key 标识，保存 payload SHA256 和提交状态，不保存请求、照片或凭据。恢复清理队列不能允许同意图盲重发，改 payload 仍是幂等冲突；未提交排队任务可明确重建。此表不导出、不随 portable 恢复回滚，无成员外键使其不因成员替换丢失，同设备目录迁移保留。已确认不可变推荐事实仍可读，不能伪造已被清理任务的成功结果。

已接受 weather DB18 仅明确配置可便携，派生天气/cache/errors不写入资料包；恢复预览复用天气领域格式及无凭据端点规则。媒体传输 hash 必须同时符合 original/display 不可变内容 ID 和字节数，不能仅重签清单就改变历史 blob。

已接受 feedback DB19 的事件、幂等收据与资产引用一并便携。不可变观察时库存快照不与当前衣物强制匹配，纠正与撤销保留原引用；恢复预览复用反馈类型、评分和选择规则，并核对来源意图、明确穿着事实归属与排除时区日期。revision1无前驱；后续明确前驱须存在、同成员同根且严格更早，不要求整根只有一条线性历史。资产引用表的成员须与反馈事件一致。未来未接受领域不预先复制；对应模块接受后接入管理事实和历史。
