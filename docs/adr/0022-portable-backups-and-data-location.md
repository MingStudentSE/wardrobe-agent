# ADR0022：便携事实备份与本机数据目录

状态：实施中，#32；独立验收前不称为采用完成。

普通备份是用户明确保存的本地明文资料包，范围包括成员、当前衣物、不可变搭配版本、穿着及护理修订、保存收据、洞察设置、历史展示引用和展示图片。原图是独立显式选项。界面说明范围与明文性质；不把普通备份称为同步密文包。

在一个 SQLite 读事务中逐行构造新的白名单事实数据库，媒体逐文件流式复制、哈希与长度校验，最后发布目录。原数据库页、客户端授权、供应商配置、OS密钥、AEAD钱包、配对记录和设备序列从未写入便携备份暂存。未采用的本机任务与模型缓存不充当跨安装业务事实；恢复后的配置与模型获取需要本机明确处理。新增已接受领域实体由对应模块接入备份白名单，并在最终联合验收覆盖，不以全库导出代替资产授权。

恢复先只读验证格式、实际数据库版本、结构、引用与所有文件hash。明确覆盖时先生成当前事实与原图的真实预备备份；展示媒体先暂存，业务记录在同一IMMEDIATE事务覆盖，失败不改变当前事实。保留旧媒体与预备备份供回退。安装凭据与设备信任不能随备份继承；ADR0012恢复材料及恢复secret独立于普通备份，恢复后的新设备须显式恢复/配对，不复制旧设备序列。

数据目录迁移是同一安装的本机搬迁，不是便携导出：复制并验证实际数据库及本机文件后才发布位置切换，旧目录保留。既有进程的共享Application入口与新CLI/MCP打开均读取新目录；失败保持原位置。此动作不能替用户读取或覆盖真实库作测试。

无需新增业务表或占用DB17；实现不能按全局数据库版本跳过其他模块实际表修复。#35负责三平台安装/升级/恢复最终发行验收及完整规模基线。
