## MVP 收尾建议

MVP 聚焦本机单用户的录入衣物 → 管理衣橱 → 手工搭配/离线推荐 → 记录穿着 → 查看统计 → 备份恢复。AI 可作为可选能力，不阻塞基础流程。完整 Beta 原规格保留，暂停扩展并不将原规格标记完成。

优先修复当前启动入口与数据版本匹配：本次启动的已有安装包仍显示“数据库由更新版本创建，请升级应用后再打开”；独立数据目录的开发进程已启动，但可用窗口尚未完成独立确认。不能把“进程运行”当作“用户已能正常使用”。不得降级或删除现有数据库。

随后在真实 macOS 原生窗口执行上述 MVP 闭环，修复实际发现的问题；统一应用入口，产出可重复启动的本机试用包，验证重启后数据和图片仍存在。MVP 暂不要求云同步、试穿或完整 Stylist。用户最新优先级为先完成三平台 MVP 安装包；正式发布仍须满足 #37 的验收门槛。
